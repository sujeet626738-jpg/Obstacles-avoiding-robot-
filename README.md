# Obstacle Avoiding Robot

An Arduino-based obstacle avoiding robot that automatically detects obstacles using an ultrasonic sensor and changes its direction to avoid collisions.

## Features
- Automatic Obstacle Detection
- Ultrasonic Sensor (HC-SR04)
- Servo Motor Scanning
- Arduino UNO Based
- Motor Driver Control
- 4WD Robot Car

## Hardware Used
- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- L298N Motor Driver
- Servo Motor
- DC Motors
- 7.4V Battery

## Future Improvements
- Bluetooth Control
- Voice Control
- Camera Integration
- AI Navigation
